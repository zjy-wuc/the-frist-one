首先是接触了vite，npm。//局部下载
对我来说，这个工具解决了3个传统网页难题：
1.ES模块文件必须通过服务器加载才能看出成品，如果每次部署那就太麻烦（本地运行一个）

2.打开一个页面，浏览器要开一大堆文件，太慢了（整合成一个文件给浏览器看）

3.文件内部改动，但是浏览器有缓存，文件名不该，内容不变（文件名哈希算法，每次改动都会使名字变化）

vite解决了这些问题。
首先下好npm后会生成package.json文件，来记录下载的配置，接下来下载的vite也会被记录，便于服务器部署配置

其次，下好vite后先来个脚本简写
"scripts": {
  "dev": "vite",
  "build": "vite build",
  "preview": "vite preview"
}
简洁
之后：
npm run dev    起服务器   
npm run build     重建dist
npm run preview   预览
基本步骤完了


第二点 react 框架
这个框架像搭积木，把网页分割成最小设计单元，设计完后再拼装。先从最小单元设计，然后用jsx文件把写好的模块拼成网页，然后继续拼，把网页jsx通过一些交互逻辑拼成总体，最后就只要用一个提交脚本了

HTML在react会退化成挂载点，实现就是jsx不停的创建，引用。

如果有个排版多次出现，可以写成组件，反之，组件不是越小越好，能复用才拆

而且react浏览器不认识，还需要额外写一个demo（入口文件）来让它在HTML上挂着

而且直接
npm create vite
直接创建这种项目，骨架自动生成
`index.html`、`src/main.jsx`、`src/App.jsx`、配置文件等
